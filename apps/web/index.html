Antes de começar

Prepare o ambiente

A construção usa o backend local e o Blockfrost. A chave privada permanece na extensão CIP-30.

Primeira execução local: instalar e iniciar
  1. No terminal, entre na pasta do workshop e execute npm install.
  2. Execute cp .env.example .env e coloque no arquivo somente o project id de um projeto Blockfrost Preprod.
  3. Carregue o ambiente com set -a; source .env; set +a.
  4. Execute npm run dev e mantenha o terminal aberto.
  5. Volte a esta página. A verificação será repetida ao recarregar.

Não informe seed phrase, chave privada ou credencial Blockfrost nesta página.

Inspecione os artefatos CBOR

Use o CBOR Nemo para decodificar o unsigned CBOR produzido nos exercícios.

Ferramenta de terceiros. Não informe seed phrase, chave privada ou credencial Blockfrost. Quem obtiver um signed CBOR válido poderá submetê-lo à rede.
Abrir CBOR Nemo
  1. Backend localInicie com npm run dev.
  2. Blockfrost PreprodO backend precisa de BLOCKFROST_PROJECT_ID.
  3. Wallet CIP-30Instale e desbloqueie uma extensão compatível.
  4. Wallet em testnetSelecione Preprod na extensão antes de conectar.
  5. Saldo de tADAA wallet precisa de ao menos um UTxO na Preprod para construir transações.

O identificador CIP-30 confirma testnet, mas não distingue Preprod de Preview. Confira o nome da rede na extensão. Sem saldo, copie seu addr_test, abra o faucet oficial, selecione Pre-production e solicite test ada. Depois, reconecte para repetir a verificação.

Exercício 3

          
Multisig 2-de-2

          
Duas chaves de pagamento diferentes precisam assinar o mesmo unsigned CBOR para movimentar o saldo do script.

        

        

          
Objetivo
Criar um script 2-de-2, bloquear tADA e desbloquear com dois witnesses.

          
Concluído quando
O unlock estiver incluído. O valor escolhido vai ao destino e o troco volta ao script.

          
Risco
Se uma chave estiver errada ou indisponível, o saldo bloqueado pode ficar inacessível.
